Field ecologist turned nature-finance specialist. I wrote the TNFD guidance on measuring changes to the state of nature and led the measurement framework behind the Verra Nature Framework. I now run Nature GP, an independent advisory, and build tools that make AI-assisted evidence synthesis auditable.
